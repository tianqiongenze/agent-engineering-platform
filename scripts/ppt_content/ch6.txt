#PAGE Prompt Cache
• 相同前缀命中推理侧缓存
• system 稳定是前提
• 动态内容放后段
>>零改造成本,先开它
#SEQ 前缀命中时序|Client,Gateway,推理服务 |0->1:请求(system 稳定);1->2:前缀 hash 查缓存;2->1:命中→跳过重算;1->2:未命中→算后写入;2->0:响应(标注 hit)|零改造成本,先开它

#PAGE Semantic Cache
• 相似问题向量匹配直接回
• 阈值:0.92+ 高置信才命中
• 失效:知识更新时全清
>>命中率 30% = 三成成本蒸发
#METRICS 语义缓存三数字|0.92^τ^相似阈值;42.2%^命中^实测;+32.3%^提升^对比仅精确|短查询(<8字)强制 bypass

#PAGE Embedding 与 RAG Cache
