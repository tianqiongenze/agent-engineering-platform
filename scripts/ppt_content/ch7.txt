#SECTION 讲次 7-1 · DeerFlow 企业级平台架构解析
#PAGE 为什么解剖 DeerFlow
• 成熟开源 Agent 平台的完整样本
• 九条架构线贯穿全课程知识点
• 学会读源码=学会二次开发
>>对照本平台,每条线都有回声
#PAGE 架构线①:请求入口
• 用户输入如何被托管成 run
• 可观察:run 全程有 ID 有 Trace
• 可控制:中断/取消/接管
>>本平台:AgentRun+GraphQL 查询面
#PAGE 架构线②:主智能体工厂
• 运行时配置 → 可运行的智能体图
• 模型/工具/提示按配置装配
• 配置即部署,变更即发布
>>本平台:AgentLoop+Provider 装配
#PAGE 架构线③:工具组装
• 注册了不代表这次能用
• 按任务动态挑工具子集
• 依赖缺失自动降级
>>本平台:Registry.discover+动态装配
#PAGE 架构线④:中间件管道 I
• 模型调用前准备上下文
• 注入记忆/检索结果/历史摘要
• 管道可插拔,顺序可编排
>>本平台:ContextWindow+compress_history
#PAGE 架构线⑤:中间件管道 II
• 输出裁决/门控/清理
• 敏感信息过滤
• 格式校验不合格打回
>>本平台:Schema 校验+反喂重试
#PAGE 架构线⑥:沙箱系统
• 工具执行的位置决定安全边界
• 本地与容器不是同一边界
• 审计与回放配套
>>本平台:LocalSandbox 同构设计
#PAGE 架构线⑦:子代理系统
• 复杂子任务委托给受限的完整代理
• 受限=工具/权限/预算三重收敛
• 结果聚合回主 Agent
>>本平台:SubagentTask+Supervisor
#PAGE 架构线⑧:技能系统
• 经验变成可安装/可审查/可重用
• 能力包:方法+工具+质量标准
>>本平台:SkillRegistry 同思想
#PAGE 架构线⑨:持久化与检查点
• 什么可恢复:状态与步骤
• 什么可查询:任务与 Trace
• 什么可审计:动作与决策
>>本平台:Checkpoint+AuditBus+Trace
#PAGE 九线合一张全景图
• 入口→工厂→装配→管道→执行
• 沙箱/子代理/技能横向支撑
• 持久化纵向兜底
>>画一遍,胜过读十遍

#SECTION 讲次 7-3 · Agent 产品化与作品集表达
#PAGE 适合 Agent 的场景
• 信息检索/文档分析/研究分析
• 代码理解/代码生成
• 客服辅助/销售运营/工单处理
• 流程自动化/企业知识问答
#PAGE 不适合 Agent 的场景
• 极强确定性任务:脚本更可靠
• 高风险零容错:资金/医疗/法律
• 规则明确:传统自动化更省
• 成本高于人工的低价值任务
>>不上 Agent 也是一种方案
#PAGE 五选一边界判断
• Chatbot:纯对话,无状态诉求
• RAG:问答有据可查
• Workflow:流程固定
• Agent:路径不确定需自主决策
• 脚本:完全确定的任务
>>选错形态是最贵的错误
#PAGE 如何避免过度 Agent 化
• 每加一层自主性问:换来什么
• 用 Workflow 能解决就别上 Agent
• 复杂度要买来价值
>>架构品味=知道不加什么
#PAGE 业务拆解七步
• 业务 SOP → Agent Loop
• 岗位任务 → Tool
• 知识资产 → RAG
• 经验方法论 → Skill
• 风险节点 → HITL
• 失败场景 → 回滚
• 业务目标 → Eval
>>Capstone C 的方法论
#PAGE 产品交付指标
• 任务完成率/人工接管率
• 平均处理时长
• 单任务成本/成本节省
• 自动化覆盖率
• 满意度/业务转化率
• 错误率/风险事件数
>>向业务方汇报的词汇表
#PAGE 从技术指标到业务价值

• 单任务成本降 70% → 年省 XX 万
• 时长天级→小时级 → 客户满意度
>>翻译能力=晋升能力
