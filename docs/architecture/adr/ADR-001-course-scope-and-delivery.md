# ADR-001:课程规模与交付节奏

- 状态:**Proposed(默认值推进,待负责人确认 D1/D4)**
- 日期:2026-10-01

## 背景
大纲未规定课时总数;交付顺序存在"成套/工程先行/课件先行"三种可行路径。

## 决策
1. 总课时 **64**(31 讲 × 2 课时 + 7 个 Lab),章节配比见《00-需求分析与总体建设方案》。
2. **成套交付**:每章 TDD 代码 → 验收 → 该章 PPT/讲稿/实验手册。

## 理由
- 64 课时覆盖大纲全部知识点且适配在职转型学员节奏;
- 成套交付使任意批次结束点都"可教学试用",风险分散、反馈及时。

## 后果
- 正:每批可验收;课件中的代码截图取自当批真实代码,不返工。
- 负:批次间有上下文切换成本(以 spec 骨架前置来缓解)。

## 回退
改课时:重排《授课计划》表格即可;改顺序:产物全部复用,仅调批次。
